# Archie

A minimal browser built on Chromium. Your tabs live in a sidebar on the left,
like Arc. No sign-in, no popups.

## Download

**[Download the latest version](https://github.com/nicklitvin/archie/releases/latest)** (Linux, x64)

```sh
tar xf archie-*-linux-x64.tar.xz
./archie-*-linux-x64/archie
```

## Features

- Tabs in a sidebar on the left, with full titles and a close button on each
- **+** opens a search box with suggestions
- Back, Forward, Reload and your previous tab at the bottom of the sidebar
- Bookmarks, tab groups and profiles
- No sign-in, no popups
- Tells you when an update is out, with patch notes
